# Quartermaster

Three AI agents run an API business from one Metal account. Each agent spends under its own on-chain mandate, and the three budgets always sum to the money the business has set aside. When a supplier raises its price past the sourcing cap, Quartermaster re-plans the split, gets a human approval bound to the exact mandate change, and rewrites the mandates on chain. The treasury agent moves earnings into Airwallex, converts USD to EUR and pays a licence fee, and the books reconcile Metal against Airwallex to the cent.

Built for the Airwallex hackathon, Kit 11 (x402 Business Agents).
